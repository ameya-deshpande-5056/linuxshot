# Keyboard Shortcuts Reference

Observed and mapped keyboard shortcuts:

## Global System Shortcuts
| Action | Default Shortcut | Configurable |
|---|---|---|
| Region Capture | `Print Screen` | Yes |
| Instant Save Fullscreen | `Shift + Print Screen` | Yes |
| Instant Upload Fullscreen | *(Disabled by default)* | Yes |

## Selection & Editing Overlay Shortcuts
| Action | Key / Combination | Context |
|---|---|---|
| Copy to Clipboard | `Ctrl + C` | While selection is active |
| Save to File | `Ctrl + S` | While selection is active |
| Select Fullscreen | `Ctrl + A` | During selection |
| Upload to Server | `Ctrl + D` | While selection is active |
| Print | `Ctrl + P` | While selection is active |
| Undo Last Annotation | `Ctrl + Z` | While annotation editor active |
| Redo Last Annotation | `Ctrl + Y` / `Ctrl + Shift + Z` | While annotation editor active |
| Cancel / Close | `Escape` | At any time during capture |
| Move Selection by 1px | Arrow Keys (`Up`, `Down`, `Left`, `Right`) | While selection is active |
| Move Selection by 10px | `Shift + Arrow Keys` | While selection is active |
| Quick Tool Selection - Pen | `P` | Selection active |
| Quick Tool Selection - Line | `L` | Selection active |
| Quick Tool Selection - Arrow | `A` | Selection active |
| Quick Tool Selection - Rectangle | `R` | Selection active |
| Quick Tool Selection - Text | `T` | Selection active |
| Quick Tool Selection - Marker | `M` | Selection active |
| Quick Tool Selection - Blur | `B` | Selection active |
